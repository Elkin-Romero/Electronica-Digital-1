# Descripción repositorio Digital UN

En este repositorio podrán encontrar las diferentes actividades, tareas, trabajos en grupo y avances que hemos realizado durante la materia de **Electrónica Digital 1**.

La idea es ir dejando aquí todo lo que hemos trabajado durante el semestre y mostrar cómo ha ido avanzando nuestro proyecto poco a poco.

Este repositorio pertenece al **grupo UART**, por lo que también encontrarán aquí la información y los avances relacionados con la parte del protocolo UART que estamos desarrollando para el proyecto.

El repositorio es público para que puedan conocer nuestro trabajo, ver lo que hemos realizado y seguir el proceso que hemos llevado desde el comienzo.

**¡Gracias por visitar nuestro repositorio y bienvenidos!**
